# 贡献皮肤

1. 新建分支并为皮肤选择稳定的短横线 ID。
2. 原媒体放入 `assets/`，生成一张 640×360 WebP 缩略图放入 `thumbnails/`。
3. 在 `catalog.payload.json` 增加条目，填写真实的字节数和 SHA-256。
4. 明确填写作者、原始作品页和许可证。接受 CC0 1.0、CC BY 4.0 与 CC BY-SA 4.0；不接受禁止再分发的图库许可、来源不明素材或仅限非商业使用的素材。
5. 不要提交 `catalog.json` 的伪造签名。维护者审核许可和内容后统一重新签名发布。

视频应使用无音轨、可循环的 MP4/WebM，并提供静态 `poster`。动画图片和视频在系统开启“减少动态效果”时必须有静态回退。所有构图应给文字阅读区留出低干扰空间，并在桌面、窄屏各检查一次裁切焦点。
