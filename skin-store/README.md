# DeepSeekHarness 皮肤商店

这是“深蓝DeepSeekHarness启动器”使用的免费开源皮肤目录。当前目录包含 63 款皮肤，其中 55 款来自 11 组原创 Seedance 2.0 母片，覆盖动态视频、1080P 定格、东方舞台、自然、太空和未来工作空间。访问公开 Gitee raw 文件不需要账号；启动器只按页获取缩略图，并在用户点击“应用”时下载原媒体。

本轮没有抓取、下载或改造网络上的美女舞蹈、影视或游戏素材。月镜舞台等人物画面均为原创成年虚构角色，不模仿真人或第三方 IP。11 段 1080P 母片总计 55 秒，再由本地确定性工具扩展为多种皮肤，避免为每张卡片重复调用付费模型。

## 安全模型

- `catalog.json`、`trust.json` 和全部资源使用固定公开 URL，不与启动器版本号绑定；在线目录拉取失败时才使用安装包内置目录。
- `catalog.json` 使用独立商店密钥签名；`trust.json` 再由启动器长期根密钥签名，因此后续商店密钥轮换无需发布新版客户端。
- 皮肤只能声明图片、动画图片、视频和受限显示参数，不能携带 JavaScript、CSS 或可执行文件。
- 每个媒体文件都必须声明 SHA-256、字节数和 MIME 类型；启动器下载后再次校验。
- 单张图片上限 25 MiB，单个视频上限 80 MiB；推荐视频控制在 50 MiB 内以兼容常见 Git 托管限制。
- 内容分级目前只接受 `everyone`。真人风素材必须明确表现为成年人，且不得露骨、冒充公众人物或暗示代言。

## 目录

```text
catalog.payload.json   维护者编辑的目录载荷
catalog.json           发布用签名目录
trust.json             根签名的在线商店信任清单
catalog-public-key.pem 当前商店公钥（供审计）
assets/                原图、动画与视频
thumbnails/            640×360 WebP 缩略图
schema/catalog.schema.json
CONTRIBUTING.md
LICENSE-ASSETS         首批原创资产的 CC0 声明
```

每页固定最多展示 20 项。缩略图会懒加载，原媒体不会随目录同步而批量下载。
