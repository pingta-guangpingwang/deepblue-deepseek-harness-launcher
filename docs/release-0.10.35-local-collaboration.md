# 0.10.35 本地协作发布验收

记录日期：2026-09-11。Connector 0.10.11。本文件记录发布前证据，不单独证明线上部署完成。

## 本轮变化

- 本地房间支持多角色协作、同目录写入排队、排队取消及可选 Git worktree；预检冲突不自动合并原分支。
- 单聊与独立窗口共享原生会话标识，重启后的续接记录保存在本地加密状态；未知执行结果阻止盲目重发。
- 网页工作区在线读取本机数据，历史使用最多 120 行滑动窗口；文件由用户点击后传输，离线清空并拒绝重放。服务器不保存聊天、文件正文或离线指令。
- 加固目录选择的取消与重复打开，增加新建空项目入口；支持官方 Claude 原生可执行文件布局。
- 修复无桌面上下文的 CLI 桥接进程覆盖桌面连接的问题。仅自动更新已识别的旧桥接代码并备份，不修改全局 Codex 配置或自定义桥接代码。
- 调整聊天角色展示、独立窗口、主题持久化和主要按钮对比度。

## 已完成的真实安装测试

在实际 0.10.35 安装与原有账号配置上完成 18 次成功原生调用：群聊 5 次、目录排队 2 次、worktree 2 次、取消测试的持有者 1 次、Cursor/DSH 各 1 次、Codex 单聊续接 3 次、Claude 单聊续接 2 次、原生桌面同会话回复 1 次。

生成的测试文件位于专项新建项目，不在用户原有项目内写入。排队取消者未执行；worktree 冲突预检未更改原分支。Codex 与 Claude 均通过跨轮随机标识续接验证，Codex 独立窗口沿用相同原生会话。文件沙箱预览及设置广播测试通过，原主题已恢复。

目录选择连续三次取消/重开测试通过，未再出现已观察到的应用挂起事件；这不代表已完全确定最初 Windows 挂起的根因。
