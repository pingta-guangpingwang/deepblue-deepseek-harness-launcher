# 本地总控协作界面：当前实现记录

> 2026-09-10 在线直读更新：已取消网页内容副本及缓存开关，复用本工作区作为网页 Shadow DOM 入口。历史现在为最多 120 行的双向滑动窗口，超出窗口的记录从本机按游标重取，锚点保持；单条超长记录完整分块读取。服务器不保存聊天/文件或离线命令。相关源码为 `online-workspace.tsx`、`history-window.ts` 和 Host `online-channel.ts`。网页只在用户点击后传输文件，离线显示未连接；下文旧的“临时云副本/同步状态”描述不再适用于新通道。

## Overview

本记录仅描述 `LocalRoomWorkspace.tsx`、`LocalPdfPreview.tsx` 与 `local-room-workspace.css` 组成的本地协作界面扩展。视觉方向继承“DeepSeek 操作台”：纸白内容、浅灰分区、中文系统字体及 DeepSeek 蓝操作强调。它不是品牌重设计，也不替代根目录 `PRODUCT.md`、`DESIGN.md` 或 `.impeccable/design.json`；这些全局权威文件保持原样。

本地执行、主控审批、完整分页记录和固定文件版本是此界面的主要信息。网页同步与旧云端房间是明确区分的入口。本文件记录界面已经表达的行为，不据此宣称云端已部署或整个产品已获发布验收。

## Colors

颜色直接引用宿主的 `--surface`、`--surface-soft`、`--text`、`--text-secondary`、`--border`、`--blue` 和 `--blue-soft`，不创建第二套品牌色。浅色宿主中纸白内容为 `#ffffff`、正文为 `#202124`、分隔线为 `#e4e6ea`、品牌蓝为 `#4d6bfe`；选中淡蓝回退值为 `#eef1ff`。

蓝色用于当前房间、内容页签、指定成员、主要操作和审批区域。状态还显示中文文字；不得仅凭颜色判断执行成功、审批完成或网页同步完成。主题变量可随宿主变化，本轮证据不构成所有主题的视觉认证。

## Typography

继承宿主 `Microsoft YaHei UI`、`PingFang SC`、`Noto Sans CJK SC`、`system-ui` 中文无衬线栈。工作区正文为 14px，栏标题为 15px，操作和任务说明主要为 13px，辅助标签主要为 12px；时间及文件摘要局部为 11px。Markdown 行高 1.75，任务与帮助说明约为 1.65。标题不采用营销展示字号。

代码块和原生数据承担真实代码与诊断内容，不用于装饰。上述局部字号是本界面的实现记录，不升级为全产品字体规范。

## Layout

桌面结构为房间栏、任务与审批栏、对话区。默认列宽为 200px / 260px / 剩余宽度，1150px 以下为 175px / 205px / 剩余宽度。各栏内容独立滚动，对话输入器位于历史区下方。房间栏底部提供智能体类型及项目目录授权入口。

900px 以下改为“房间 / 任务与审批 / 对话”按钮切换单个面板；选择房间后切换到对话。550px 以下成员编辑字段改为单列，并缩减弹窗及历史区边距。长消息、名称与任务文本允许折行；代码与表格在自身区域横向滚动。此处断点仅适用于本地协作表面。

## Elevation & Depth

普通内容以一像素边界与浅色背景区分，不依赖卡片阴影。预览和房间编辑浮层使用半透明遮罩 `rgba(15,23,42,.38)`，承载明确的临时任务。没有引入新的装饰性深度语言。

## Shapes

主工作区圆角 12px，弹窗 14px；房间行、文件块和代码块使用 8px，输入控件 7px。按钮继续复用宿主主要、次要与图标按钮样式。局部容器圆角不用于重写根设计规范。

## Components

### 房间与审批台账

房间显示名称、运行状态、审批档位与同步状态。新房间默认“帮我批准”，支持“请求批准”和“完全批准”；启用完全批准需界面确认，文案限定为所选项目范围。编辑器要求成员名称、称呼、智能体与授权项目，并显示未具备统一审批接口的适配器不参与代审。

审批项展示成员、操作类别、原因与命令或路径。审核中显示等待状态；可决定时提供“批准一次 / 拒绝”。台账显示排队、执行、待批准、待核对、完成、失败、取消等文字；进行中的轮次可取消，未知状态提供只读原生核对入口。界面有操作互斥与等待反馈，不能把等待或错误当作批准。

### 对话、历史和原生记录

内容页签为“对话 / 原生执行记录 / 文件”。初始读取最多 100 项，较早记录每次读取 50 项；已载入本地历史不受云端窗口裁剪。阅读较早内容时保留位置，以“回到最新记录”提供返回动作。审批档位变化保留已加载记录。

原生记录先展示可读标题、状态、命令和正文；完整 JSON 位于“查看完整原生数据”折叠项。只呈现原生接口提供的可见信息。Markdown 的图片引用不自动加载外部图片，HTTP(S) 链接通过宿主外部打开动作处理。

输入器支持交给主控或指定成员、附加本地文件、Enter 发送及 Shift+Enter 换行；中文输入法组合输入中的 Enter 不发送。内容页签切换保留草稿，房间或账户切换会清除草稿、收件成员和待发附件。不确定发送结果保留内容及原请求标识，供重试使用。

### 文件与预览

文件行显示名称、字节大小、本地或临时云副本状态及 SHA-256 前缀。附件选择会固定本地版本；文件面板读取本地版本，不自动上传。预览、另存与本地应用查看是独立操作，界面显示读取、保存、打开、取消或失败反馈。

图片以实际图像元素解码，失败时显示恢复说明。PDF 使用 PDF.js 从本地 capability URL 绘制 canvas，提供页码、上一页、下一页、读取进度、绘制状态及错误文字；不运行 PDF 动作或脚本。其他内嵌内容使用空 sandbox iframe，不支持预览的类型明确引导另存。预览页脚始终标注“本地固定版本”。

### 可访问性与状态

主要输入、图标操作、PDF 翻页和面板导航有可访问名称。房间与成员按钮使用 `aria-pressed`，内容页签使用 `role=tab` 和 `aria-selected`。按钮、输入、选择框、文本框及折叠摘要有可见蓝色 2px 焦点轮廓，偏移 2px。

操作等待及成功反馈使用 `role=status`，错误使用 `role=alert`；PDF 容器使用 `aria-busy`。空房间、无文件、无可用项目、加载中及失败均有文字。预览弹窗进入时定位焦点，支持 Tab 循环、Escape 关闭及关闭后恢复先前焦点。房间编辑器提供初始输入焦点、Tab 循环与非保存状态下的 Escape 关闭。PDF canvas 带页码名称，但当前没有可选择的文字层；本轮不能据此声称 PDF 全文具备屏幕阅读器等价访问。

## Do's and Don'ts

- Do 延续宿主品牌变量，保持房间、审批与对话的操作层级。
- Do 将可读执行内容放在完整原生数据之前，将失败、等待与同步确认区别显示。
- Do 保留完整本地历史分页及固定文件版本语义；网页副本状态以返回值为准。
- Don't 将本界面局部值推广成新的全局设计系统；不要修补无关历史文档。
- Don't 将本地预览、合成数据测试或源码实现描述为已部署云端或全产品发布认证。

本轮界面 QA 的证据边界：`output/playwright/local-control/1789018570802/report.json` 标记 `passed: true`、`synthetic: true`、`productionWrites: false`。覆盖编译后的 renderer/preload/Host 与合成 SQLite 房间、125 条消息真实分页、同一本地文件服务中的两页 PDF 实际渲染及图片解码、页签切换草稿保留、窄屏无水平溢出。目录中的 desktop-room、desktop-image、desktop-pdf-page-1、desktop-pdf-page-2 和 mobile-room 截图为对应视觉证据。

`output/playwright/local-control-states/1789019938952/report.json` 同样标记合成测试通过，覆盖审批档位切换保留历史、IME Enter 不发送、审批等待与重复点击阻止、不确定发送重试保留请求标识、移动任务及原生面板无水平溢出；对应截图为 desktop-approval、desktop-pending、desktop-error、desktop-native、mobile-native 和 mobile-tasks。
