# 本机智能体数据优先：本地验收记录

日期：2026-09-07。分支：codex/launcher-agent-host。

## 已实现

- 默认显示本机原生项目和会话，网站同步与托管独立切换；未绑定本机智能体时不再用服务器历史冒充本机数据。
- 读取 Codex、Claude Code、OpenClaw 已有索引；本机扫描不等于授权远程执行。向网站同步需要选定项目并沿用已有登录与设备授权路径。
- Codex / Claude Code 本机发送通过 IPC 调用原生运行程序，不依赖网站登录、签到或网站额度；沿用智能体自身账号、权限和模型限制。
- 本地文件选择器可以交付图片、音视频和一般文件；图片沿用原生图片输入，其他附件提供本地文件路径。文件可交付不等于模型能够理解视频或音频。
- Codex 模型选择来自本机原生模型缓存；没有模型目录时使用原生默认值，不虚构模型或参数。
- 优先使用 Codex 桌面版配套 CLI，避免旧 npm CLI 无法读取新版模型缓存。
- 兼容新版原生会话的 item_completed / exec 来源，过滤内部过程和子智能体记录。刷新和重启后仍能读取真实最终回复。
- 同步刷新等待目录快照和心跳确认；目录修改时间不再被解释为正在运行。

## 实测证据

使用隔离启动器配置、真实 Windows 用户的原生智能体数据及登录，未复制密钥、未写网站。

- 真实 Codex 发送返回 LOCAL_AGENT_OK，退出码 0，界面状态完成。
- 重新启动测试窗口，重新扫描并在界面打开同一原生会话，用户消息与最终回复保留。
- 实测扫描 38 个项目、98 个会话、7 个原生模型（本机数据会持续变化）。
- 会话首次显示滚动到底部；无新增消息的轮询不改变阅读位置。
- launcher 29 项专项回归通过；connector 12 项专项回归通过；typecheck 和 build 通过。
- 报告：output/playwright/local-authority/1788754436467/report.json（真实发送）；output/playwright/local-authority/1788755804822/report.json（重启回读）。
