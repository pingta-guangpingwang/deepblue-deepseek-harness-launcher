# PC 智能体托管：第一阶段实现与发布门禁

状态：本地开发候选版 0.10.34，未发布到公网。网站配套分支为
`codex/agent-host-site`，启动器分支为 `codex/launcher-agent-host`。

## 已实现的闭环

- 登录现有 AI历史书账号，在工作台绑定电脑；设备凭据和实例交互密钥仅通过
  主进程使用系统 safeStorage 加密保存，不进入 renderer、命令行或普通配置。
  设备注册前先加密持久化安装标识与随机凭据，响应丢失后用相同凭据幂等续接，
  不重复注册或轮换有效密钥。网页撤销后，本机可幂等解绑再重新绑定。
- 有限 PATH 探测 Codex、Claude Code、QClaw/OpenClaw。Windows 官方 npm shim
  只转换固定官方包的合法 bin 路径；不接受云端给出的程序或参数。
- 本机目录选择授权项目。每个实例独立状态文件、独立 Codex 回环端口、独立
  connector 子进程。原生会话通过既有 connector 发现与续接，不新建云端替代会话。
- 托管在主进程模块中运行，关闭主窗口后继续驻留托盘；渲染器刷新不停止连接。
  退出登录立即停止领取新远程任务，当前工作安全结束。忙碌时阻止模块切换，
  彻底退出会提示任务将中断。
- 网站设备 API 独立于任务 API，因此设备在线但智能体停止时，可以发送远程
  启动命令。服务端校验账号与绑定、60 秒排他租约、120 秒命令期限、忙碌状态，
  指令编号去重并持久化回执；本机执行前再检查同一授权。
  新实例的设备绑定中断时保留一次性密钥：心跳若确认已经绑定则完成恢复；
  否则提示本机点击“启动”重试同一实例，不在后台重新授权可能被网页解绑的实例。
- 原生工作台固定三栏，窄屏切页；复用网站项目、会话、任务 ID 和最近原生历史。
  发送重试不更换请求编号；输入法 Enter 不误发；阅读旧内容时不强制滚到底部。
- 现有每日签到规则保留，通过工作台内签到按钮完成，不另造账号或计费链路。
- 新 `agent-host` 运行模块由现有签名目录/下载校验/原子安装管理，更新不要求
  替换 Electron。基础壳首次需要升级到 0.10.34 以增加 IPC 和模块类型；旧壳显示
  升级提示。模块版本按内容哈希产生。模块加载失败由更新事务回滚，冷启动可退回
  上一个或内置版本。资源目录迁移包含加密托管数据，原目录仍保留。

## 不能扩大宣传的边界

- 本阶段设备控制面采用串行 HTTPS 心跳（有待处理操作 5 秒、空闲 15 秒），
  失败退避至 60 秒并加随机抖动；尚未实现 WebSocket/SSE 推送。
- PC 必须开机、联网且启动器仍运行。不能唤醒断电/休眠电脑，也不会绕过锁屏。
- “发现命令”不等于“账号已登录”。Codex 使用真实本机就绪探测；暂时不能被动
  验证的其他 CLI 返回未知状态，由任务返回的原生错误说明，不虚报可用。
- DeepSeek Harness 当前仍从首页启动，尚未增加与其他适配器同构的 DSH 原生
  会话适配器。TRAE/WorkBuddy/CodeBuddy 暂不在本机添加列表中。
- 旧独立 connector 的自动接管尚未实现：不能只复制密钥重启另一个进程；后续
  接管必须停止旧实例、保留状态及租约，避免竞争写入同一原生会话。
- “给 AI 一条提示词即可检测、下载安装、配对”的统一引导仍属下一阶段。

## 本地构建

`npm run build` 构建基础壳入口、renderer 和内置 agent-host。
`npm run agent-host:build` 产生小型 tar.gz 模块和单条发布记录。
默认使用仓库内 `vendor/agent-connector`，新克隆不依赖开发者电脑上的绝对路径。
`AILISHISHU_CONNECTOR_SOURCE` 可指向对应网站仓库的 `packages/agent-connector`；
通过 `build-agent-host-module.mjs --vendor-from-source` 机械同步已审查源代码快照，
禁止同步私有配置、密钥或运行状态。
生成记录不会覆盖完整线上目录，也没有自动签名或上传。

`npm run hot-update:agent-host` 在生成并校验本地托管包 SHA-256 后，仅替换
`runtime-modules.generated.json` 的 agent-host 条目，保留 Node/Harness/pnpm/UI
及其他模块。缺少现有完整目录时拒绝发布，不能拿单条记录覆盖生产目录。
`npm run modules:build` 已接入这一步；重建核心不再删除其他模块的压缩包或目录条目。
`catalog:prepare` 缺少五个必需条目中的任一条会失败，避免漏发托管热更新。

## 发布门禁

1. 在真实 MySQL 5.7 测试库对网站 076 迁移执行两次，确认与已有表外键兼容。
   静态结构与 PHP 断言不替代真实数据库执行。
2. 部署测试接口，用专用测试账号完成电脑绑定、手机远程启动、原生会话续接、
   断网恢复、账号退出/撤销与 busy 热更拒绝。不得用合成界面数据冒充此项通过。
3. 构建 0.10.34 基础壳安装候选包，真实覆盖自定义安装位置，再做公网全新安装。
4. 将模块合并进完整生产运行目录，用既有受保护私钥签名；先上传模块并校验
   Gitee/OSS/GitHub 公共读取，再发布目录和基础壳，最后更新下载入口。
5. 旧启动器升级提示与新工作台入口通过公网实际回下载后才宣布上线。
