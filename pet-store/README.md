# DeepSeekHarness 宠物商店

这是“深蓝 DeepSeekHarness 启动器”的免费开源宠物目录。当前目录包含 56 个宠物，其中 50 个是本轮新增的原创透明动态宠物。启动器每页最多读取 20 个缩略图，只有用户点击应用时才下载宠物原图。

宠物资源由项目使用图像生成工具原创制作，并以 CC0-1.0 释出。本轮先设计 5 张、每张 10 个角色的原创母稿，再使用 25 秒 720P Seedance 2.0 母片制作眨眼、呼吸、耳尾轻摆等动作，最后在本地裁切、去背景并压成透明动态 WebP。目录只接受 PNG、JPG、WebP、GIF，不接受脚本、HTML、模型权重或可执行文件。

新版宠物支持帧动画、悬停回应、点击动作、双击爱心、定时主动问候、拖动与位置记忆；交互全部由受限声明字段驱动，不从商店执行脚本。

## 目录结构

- `catalog.json`：带 Ed25519 签名的在线目录。
- `trust.json`：由启动器长期根密钥签名的在线信任清单，允许在不升级客户端的情况下安全轮换商店密钥。
- `catalog-public-key.pem`：当前商店公钥，供独立审计。
- `catalog.payload.json`：待签名的目录正文。
- `assets/`：宠物原媒体。
- `thumbnails/`：用于列表的轻量缩略图。
- `schema/catalog.schema.json`：目录 JSON Schema。

目录、信任清单和媒体资源均使用固定公开 URL，不与启动器版本绑定。启动器优先拉取在线目录，只有网络不可用或校验失败时才使用安装包内置目录。

## 使用与参与

公开仓库无需登录即可读取。提交新宠物时同时提供原媒体、缩略图、许可证和目录项；详情见 `CONTRIBUTING.md`。用户也可以在启动器中导入自己的宠物，文件只会保存在本机，不会自动上传。
